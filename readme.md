# learnfront

Käivitamine:

```sh
bun install
bun run dev
```

ToDo lehel saab uuele asjale valida olulisuse: kõrge, keskmine või madal.
Kõik kolm nimekirja on olulisuse järgi sorteeritud. Punane tähistab kõrget,
kollane keskmist ja roheline madalat olulisust.

Important sakk näitab sama nimekirja kõige olulisemaid asju.
Modals sakil on varasem tunnitöö.

Projekti ehitamine: `bun run build`.
